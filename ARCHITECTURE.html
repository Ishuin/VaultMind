System Architecture

VaultMind

Full-stack knowledge management platform with multimodal RAG pipeline, local AI inference, and BYOK architecture

01 — System Overview

Four-tier architecture: React frontend → FastAPI backend → dual storage (PostgreSQL + LanceDB) → local/cloud LLM inference

🖥️

Frontend

React · TypeScript · Vite
  • shadcn/ui + Tailwind CSS with multi-theme support
  • React Context for state management
  • JWT auth stored in localStorage
  • REST API via typed apiFetch() wrapper
  • Chat UI with streaming response support
  • Document upload with progress feedback
HTTP / JSON
⚡

Backend

FastAPI · Python 3.11+
  • JWT auth (OAuth2 + passlib bcrypt)
  • Multimodal document processing pipeline
  • RAG chat with context retrieval + generation
  • LangChain RecursiveCharacterTextSplitter
  • Sentence-transformers embeddings (384-dim)
  • Streaming SSE + non-streaming LLM responses
Read / Write
🗄️

Storage

PostgreSQL + LanceDB
  • PostgreSQL — users, document metadata, sessions
  • LanceDB — vector chunks (384-dim embeddings)
  • SQLAlchemy ORM with async support
  • Prefiltered vector search by user_id
  • Cascade deletes for document cleanup
Inference
🧠

LLM Layer

Ollama · NVIDIA NIM · BYOK
  • Ollama — local model inference (privacy-first)
  • NVIDIA NIM — cloud API fallback
  • OpenAI-compatible chat endpoint
  • SSE streaming for real-time responses
  • Multi-model selection per user preference
02 — RAG Pipeline

Multimodal ingestion supporting PDF (OCR + text), DOCX, TXT, Markdown, images (VLM), and graphs — with intelligent chunking and vector storage

📥

Ingestion Pipeline

6 Steps
01
Upload

Multipart form upload — PDF, DOCX, TXT, MD, images (PNG/JPG), or paste text content

02
Extract

pypdf for PDF text + OCR fallback · python-docx for DOCX · Vision Language Models (VLM) for images and graphs · Markdown parser for .md files

03
Chunk

RecursiveCharacterTextSplitter — 1000 chars, 100 overlap, preserves semantic boundaries

04
Embed

all-MiniLM-L6-v2 — 384-dimensional dense vectors via sentence-transformers

05
Store

LanceDB document_chunks table with metadata (filename, chunk_index, source_type)

06
Index

Metadata row in PostgreSQL documents table with processing status and content type

💬

Query Pipeline

5 Steps
07
Query

User question from chat interface — natural language, no special syntax required

08
Embed Query

Same MiniLM-L6-v2 model encodes user query into 384-dim search vector

09
Search

Vector similarity search filtered by user_id — top-K retrieval from LanceDB

10
Context

Top-K chunks joined into context string with source attribution metadata

11
Generate

System prompt + context + user query → Ollama/NIM generates grounded answer with citations

03 — Key Features

Enterprise-grade capabilities built for serious knowledge workers

🔒
Local-First RAG

All embeddings and inference happen locally via Ollama — your data never leaves your machine

🔑
BYOK Architecture

Bring Your Own Keys for any LLM provider — no subscriptions, no vendor lock-in

📸
VLM Processing

Vision Language Models extract text from images, charts, diagrams, and scanned documents

📊
Markdown Tables

Native parsing of Markdown tables and structured content for accurate knowledge retrieval

🔍
OCR Fallback

Optical Character Recognition for scanned PDFs and image-based documents

⚡
Streaming Responses

Real-time SSE streaming for instant feedback during LLM generation

🗑️
Cascade Deletes

🎨
Multi-Theme UI

Light, Dark (Obsidian Vault), and Sky (Deep Spring Sky) themes with instant switching

05 — API Endpoints

RESTful API with JWT authentication, OpenAPI docs at /docs

🔐

Authentication

POST /api/v1/login/access-token OAuth2 token login (form-urlencoded) Public
👤

Users

POST /api/v1/users/ Create new user account Public
GET /api/v1/users/ List all users JWT
GET /api/v1/users/me Get current authenticated user JWT
📚

Sources (Documents)

GET /api/v1/sources/ List user's uploaded documents JWT
POST /api/v1/sources/upload Upload document — triggers full RAG pipeline JWT
DEL /api/v1/sources/{document_id} Delete document + cascade LanceDB chunks JWT
💬

Chat (RAG)

GET /api/v1/chat/models List available Ollama models JWT
GET /api/v1/chat/nim-models List NVIDIA NIM cloud models JWT + NIM Key
POST /api/v1/chat/query RAG query — retrieve context → prompt → LLM response JWT
🔧

Utility

GET / Welcome message Public
GET /health Health check endpoint Public
