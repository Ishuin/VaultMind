1 — System Overview
🖥️

Frontend

React · TypeScript · Vite
  • React Context state management
  • shadcn/ui + Tailwind CSS
  • Token-based auth (localStorage)
  • REST API via apiFetch()
  • Chat UI with streaming
  • Document upload + management
→ HTTP / JSON
⚡

Backend

FastAPI · Python
  • JWT auth (OAuth2 + passlib)
  • Document processing pipeline
  • RAG chat with context retrieval
  • LangChain text splitting
  • Sentence-transformers embeddings
  • Streaming + non-streaming LLM
→ Read / Write
🗄️

Storage

PostgreSQL + LanceDB
  • PostgreSQL — users, document metadata
  • LanceDB — vector chunks (384-dim)
  • SQLAlchemy ORM for SQL layer
  • Prefiltered vector search by user
  • Cascade deletes for cleanup
→ Inference
🧠

LLM

Ollama · NVIDIA NIM
  • Ollama — local model inference
  • NVIDIA NIM — cloud API fallback
  • OpenAI-compatible chat endpoint
  • Streaming via SSE
  • Multi-model selection

3 — Database Schemas
👤

users

PostgreSQL
ColumnTypeConstraints
id INTEGER PK auto-increment
email VARCHAR UNIQUE, NOT NULL, indexed
username VARCHAR UNIQUE, NOT NULL, indexed
hashed_password VARCHAR NOT NULL (passlib bcrypt)
full_name VARCHAR nullable
is_active BOOLEAN default true
is_superuser BOOLEAN default false
created_at TIMESTAMPTZ server_default now()
updated_at TIMESTAMPTZ on update now()
📄

documents

PostgreSQL
ColumnTypeConstraints
id INTEGER PK auto-increment
filename VARCHAR NOT NULL
content_type VARCHAR nullable
user_id INTEGER FK → users.id, NOT NULL
created_at TIMESTAMPTZ server_default now()
🧬

document_chunks

LanceDB
FieldTypeDetails
id STRING Format: doc_{id}_chunk_{index}
document_id INT FK → documents.id
user_id INT Used for prefiltered vector search
text STRING Raw chunk text content
vector VECTOR(384) all-MiniLM-L6-v2 embedding
metadata STRING JSON — filename, chunk_index
4 — API Endpoints
Authentication
POST /api/v1/login/access-token OAuth2 token login (form-urlencoded) Public
Users
POST /api/v1/users/ Create new user account Public
GET /api/v1/users/ List all users JWT
GET /api/v1/users/me Get current authenticated user JWT
Sources (Documents)
GET /api/v1/sources/ List user's uploaded documents JWT
POST /api/v1/sources/upload Upload PDF/DOCX/TXT — triggers full RAG pipeline JWT
DEL /api/v1/sources/{document_id} Delete document + LanceDB chunks JWT
Chat (RAG)
GET /api/v1/chat/models List available Ollama models JWT
GET /api/v1/chat/nim-models List NVIDIA NIM cloud models JWT + NIM Key
POST /api/v1/chat/query RAG query — retrieve context → prompt → LLM response JWT
Utility
GET / Welcome message Public
GET /health Health check endpoint Public
